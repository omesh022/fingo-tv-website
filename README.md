# Fingo TV Website

Public website for the Fingo TV Android app: a media player and playlist (IPTV) player by Omesh Kumar.

Live site: https://fingo-tv.vercel.app
Privacy Policy: https://fingo-tv.vercel.app/privacy

## Pages

- `/` - Landing page (index.html)
- `/privacy` - Privacy Policy (privacy.html)
- `/terms` - Terms of Use (terms.html)
- `/copyright` - Copyright and DMCA notice (copyright.html)
- `/licenses` - Open Source Licenses (licenses.html)
- `404.html` - Custom not found page

## Tech

Plain HTML and CSS only. No frameworks, no build step, no JavaScript, no tracking, no cookies.
Clean, minimal editorial design (forced light mode, solid brand palette, borderless architectural layout).
Shared styling lives in `style.css`. Deployed to Vercel as a static site; `vercel.json` enables clean URLs so pages open without `.html`.
